🎬 Netflix — Vantagens e Desvantagens

Este projeto é um site desenvolvido em HTML, CSS e JavaScript com o objetivo de apresentar as principais vantagens e desvantagens da Netflix.

📌 Sobre o projeto

O site possui um visual inspirado nas cores da Netflix, utilizando principalmente:

🔴 Vermelho #E50914
⚫ Preto #000000
🌑 Cinza escuro #141414
⚪ Branco #FFFFFF

A página apresenta informações de forma simples, organizada e responsiva.

✨ Funcionalidades
Página inicial com apresentação do tema.
Menu de navegação.
Seção de vantagens.
Seção de desvantagens.
Tabela comparativa.
Conclusão.
Design responsivo para celulares e computadores.
Animação dos cards ao aparecerem na tela.
Rolagem suave entre as seções.
🗂️ Estrutura do projeto
site-netflix/
│
├── index.html
└── README.md


O projeto foi feito em um único arquivo HTML, contendo o CSS e o JavaScript internamente.

🚀 Como executar
Baixe ou clone o projeto.
Abra a pasta do projeto.
Abra o arquivo index.html em qualquer navegador.
Navegue pelas seções do site.

Não é necessário instalar nenhuma biblioteca ou programa adicional.

🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
🎯 Objetivo

O objetivo deste projeto é apresentar, de maneira visual e educativa, os pontos positivos e negativos de utilizar uma plataforma de streaming como a Netflix.

📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela, incluindo:

💻 Computadores
📱 Celulares
📟 Tablets
📄 Licença

Este projeto foi desenvolvido para fins educacionais e acadêmicos.
